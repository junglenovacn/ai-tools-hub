## 内链策略矩阵

### 规则
1. **每篇文章至少包含 2 条内链**
2. **优先链向同支柱内其他文章**（增强 topic authority）
3. **每个支柱页至少被 3 篇文章链入**
4. **"免费工具"系列互相引用**（形成横向网络）
5. **锚文本使用目标关键词变体**，不重复使用完全相同锚文本

### 支柱页链入目标
| 支柱页 | 目标被链入次数 | 来源文章 |
|--------|---------------|----------|
| #1 Cursor vs Copilot vs Windsurf | ≥4 | #2, #3, #4, #5 |
| #6 Midjourney vs FLUX vs Ideogram | ≥4 | #7, #8, #9, #10 |
| #11 Sora Alternatives | ≥4 | #12, #13, #14, #6 |
| #15 AI Writing for SEO | ≥3 | #16, #17, #18 |
| #18 AI Productivity | ≥3 | #19, #20, #16 |

### 跨簇链接（增强站点权重传递）
- 所有 "free tools" 文章互链：#8 ↔ #16 ↔ #19
- 所有 "comparison" 文章互提（"see also our comparison of..."）
- AI Hub 首页/About 页链向全部 5 个支柱页

## 写作时 SEO Checklist

每篇文章发布前确认：
- [ ] Title 含 primary keyword 且 < 60 字符
- [ ] Description 含 primary keyword 且 < 155 字符
- [ ] Slug 含关键词，用连字符，全小写
- [ ] H2/H3 中自然包含 secondary keywords
- [ ] 正文前 100 词内出现 primary keyword
- [ ] 内链 ≥ 2 条，锚文本为关键词变体
- [ ] Tags 按照上面分类准确标注
- [ ] Categories 双标签：["AI Tools", "<子分类>"]
- [ ] 文末 CTA 或 "Related reads" 区块
