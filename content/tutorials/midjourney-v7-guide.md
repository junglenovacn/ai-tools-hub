## What is Midjourney?

Midjourney is an AI image generation tool that creates stunning artwork from text descriptions. Version 7 represents a massive leap in quality, coherence, and user control.

## Getting Started

### Step 1: Create an Account

1. Visit [midjourney.com](https://midjourney.com)
2. Sign up with your email or Discord account
3. Choose a subscription plan (starts at $10/month)

### Step 2: Access the Editor

Midjourney V7 introduces a web-based editor at midjourney.com. You can also still use Discord.

### Step 3: Your First Image

Type a prompt in the text box:

```
A cozy coffee shop in Tokyo during cherry blossom season, 
warm lighting, film photography style
```

Click "Create" and wait 30-60 seconds for your image.

## Prompting Techniques

### Basic Structure

```
[Subject] + [Setting] + [Style] + [Mood] + [Technical details]
```

### Examples by Category

**Photorealistic:**
```
Professional headshot of a woman, studio lighting, 
shallow depth of field, Canon EOS R5, 85mm lens
```

**Illustration:**
```
Children's book illustration of a fox reading in a library, 
watercolor style, warm palette, whimsical
```

**Product Design:**
```
Minimalist smartwatch concept, floating on white background, 
product photography, soft shadows, 4K render
```

## Key Parameters

| Parameter | Effect | Example |
|-----------|--------|---------|
| `--ar` | Aspect ratio | `--ar 16:9` |
| `--s` | Stylization (0-1000) | `--s 750` |
| `--c` | Chaos/variety (0-100) | `--c 30` |
| `--q` | Quality | `--q 2` |
| `--no` | Negative prompt | `--no text, watermark` |

## V7 New Features

### Improved Text Rendering
V7 can now render text accurately in images — a long-standing weakness of AI image generators.

### Better Hands and Anatomy
Significantly improved human anatomy, especially hands and fingers.

### Image References
Upload reference images to guide the style:
```
[uploaded image] A portrait in this exact style but of an elderly man
```

## Pro Tips

1. **Be specific** - "golden hour lighting" > "nice lighting"
2. **Use artist references** - "in the style of Studio Ghibli"
3. **Iterate** - Use variations and remix to refine
4. **Negative prompts** - Exclude unwanted elements with `--no`
5. **Experiment with aspect ratios** - Different ratios suit different content

## Common Mistakes

❌ Prompts that are too short: "a cat"
✅ Better: "A fluffy orange tabby cat sitting on a windowsill, afternoon sunlight, bokeh background, photography"

❌ Contradictory styles: "realistic cartoon painting"
✅ Pick one: "hyperrealistic photography" OR "Studio Ghibli anime style"

## Conclusion

Midjourney V7 is the most capable AI image generator available today. With practice and the techniques above, you can create professional-quality images for any purpose — from social media to professional design work.

Start with simple prompts and gradually add complexity as you learn what works.
